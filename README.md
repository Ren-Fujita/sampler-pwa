# サンプラー PWA — リファクタリング第2版（v5）

iOS 27上端ぼかし対策版（v4）を基に、状態を持つ処理をさらに分離しました。画面、iOS 27のぼかし対策、保存先・保存形式、音声の手動復旧と画面復帰時の音声処理は維持しています。

## 公開中のGitHub Pagesを更新する

1. ZIPを展開します。
2. 公開中のGitHubリポジトリで `index.html` がある場所を開きます。
3. Add file → Upload files から、展開した**中身全体**をアップロードしてmainへ保存します。新しい `js/autosave.js`・`js/edit-transport.js`・`js/voice-store.js` も必須です。
4. Pagesの `Deploy from a branch / main / (root)` 設定を引き続き使います。ビルドやnpm installは不要です。
5. 公開への反映後、iPhoneをオンラインにし、メニュー →「アプリの更新を確認」→「保存して更新を適用」を選びます。

ZIPそのものや親フォルダーではなく、中のファイルと `js`・`icons` フォルダーをアップロードしてください。同じURLのまま更新できます。

## 今回整理した処理

- `js/autosave.js`: 自動保存の待ち行列、変更音源の追跡、保存失敗後の再試行と状態表示。
- `js/edit-transport.js`: 編集中の再生・一時停止・再生位置の移動と、非同期再生の取り消し。選択状態・音声・表示への依存を明示。
- `js/voice-store.js`: パッドごとの発音、重なった音、停止中の音、最古・最新の音の追跡。
- `js/app.js`: 上記を組み合わせる役割へ整理。1667行から1474行へ縮小。

追加の機能や音声自動復旧は入れていません。既存の「音声を復旧」を引き続き使えます。

## ファイル構成

```text
index.html                 画面と起動
styles.css                 スタイル、iPhoneのセーフエリアとぼかし対策
pwa.js                     オフライン状態と手動更新
sw.js                      全実行ファイルのオフラインキャッシュ（v5）
manifest.webmanifest       ホーム画面アプリの設定
icons/                     アプリアイコン
js/
  app.js                   アプリ全体の連携
  autosave.js              自動保存の調整
  edit-transport.js        編集モードの再生制御
  voice-store.js           発音の管理
  config.js                定数・上限・保存領域の識別子
  sample.js                サンプルの初期値と時間の計算
  presets.js               標準音源の生成
  session.js               設定の検証
  session-storage.js       IndexedDBの読み書き
  backup-codec.js          バックアップの読み書き
  audio-utils.js           音声出力経路とAudio Sessionの設定
  waveform.js              波形の集計と描画
tests/                     自動テストと合成した互換性確認データ
package.json               テスト実行設定
.nojekyll                  GitHub Pagesの静的配信設定
README.md                  この手順書
```

`tests/`と`package.json`は開発用で、アプリの実行には不要です。公開しても動作に影響しません。`tests/fixtures/`のバックアップは合成した短い波形で、取り込んだ実際の音源を含みません。

## 互換性と検証

保存領域 `sx12-local-sampler-v1`、保存バージョン1、現在の `.sx12` と旧JSONバックアップの対応を維持しています。標準音源12個のPCMと、バックアップの書き出しは旧版とバイト単位で一致します。

32件の自動テストが通過しています。旧版との互換性、壊れたバックアップの拒否、自動保存の同時編集と失敗時の再試行、編集プレビューの再生・一時停止・シーク、モード切り替えや停止による保留中再生の取り消し、複数発音の管理、PWA更新前の保存確認、ルートとサブフォルダーでのオフライン配信を検証しました。ブラウザ・音声機器を必要とする部分には模擬環境を使っています。

モジュールの読み込みと組み立て、初期保存データの一致、画面・CSS・iOS 27対策・音声復旧の処理の維持も確認しています。ブラウザ上の実操作とiPhone実機での動作は未確認です。

Node.jsがあれば、展開したフォルダーで次を実行できます。依存パッケージは不要です。

```text
node --test tests/*.test.mjs
```

アプリのコードを変更するときは、`sw.js`のキャッシュのバージョンも変更してください。実行に必要なファイルを増やす場合は`SHELL`にも追加します。ES modulesのため、HTMLの直接起動ではなくHTTP/HTTPSで配信してください。

## iOS 27の上端ぼかしについて

v4に追加した固定要素による回避策をそのまま維持しています。この方法はAppleが保証するAPIではなく、開発者のiOS 27実機調査に基づく対策です。実機でぼかしが消えるかは引き続き確認が必要です。

参考: [固定要素による対策の実機調査](https://qiita.com/na-trium-144/items/0add98a80ca2391e3f17)。
