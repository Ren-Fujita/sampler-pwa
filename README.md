# サンプラー PWA — リファクタリング版（v7）

音量改善版（v6）の動作を保ちながら、主音量と画面サイズ調整の処理を整理しました。

## 今回整理した内容

- `js/master-volume.js`: 主音量の値、ミュート解除時に戻す音量、表示、入力操作を一か所で管理します。音声への反映と自動保存はアプリから渡す処理へつなぎます。
- `js/layout.js`: 画面サイズ・表示領域・パッドの密度・画面の回転やサイズ変更への対応をまとめました。
- `js/app.js`: 上記を組み合わせ、音声・保存・画面との連携を担います。
- 保存した音量を読み戻す処理、音声へ反映する処理、画面に表示する処理を分け、再描画だけで音量変更や自動保存を繰り返さないよう責任を明確にしました。

## 維持している動作

- 音量バーは1%未満の細かな値で操作できます。表示・読み上げは0〜100%の整数で、1%刻みです。
- 音量は操作時点で反映します。音量が徐々に追従する処理や待ち時間は追加していません。
- ミュート解除、保存、復元でも細かな音量の値を保持します。
- キーボード操作、パッドの再生、音声の手動復旧、保存済みの音源、既存のバックアップ形式を維持しています。
- 画面のHTML・CSS、iPhoneの表示領域、上端ぼかし対策はv6と同じです。

## 公開中のGitHub Pagesを更新する

1. ZIPを展開します。
2. 公開中のGitHubリポジトリで `index.html` がある場所を開きます。
3. **Add file → Upload files** から、展開した**中身全体**をアップロードしてmainへ保存します。新しい `js/master-volume.js`・`js/layout.js` も必須です。
4. Pagesへの反映後、iPhoneをオンラインにします。
5. サンプラーのメニューから **「アプリの更新を確認」→「保存して更新を適用」** を選びます。

ZIPそのものや親フォルダーではなく、中のファイルと `js`・`icons` フォルダーをアップロードしてください。ビルドやnpm installは不要です。Pages設定は `Deploy from a branch / main / (root)` を引き続き使えます。

## 確認した内容

48件の自動テストが通過しています。音量の連続操作と整数表示、即時反映、ミュート解除、保存・復元、画面サイズ・縦横表示の切り替えに加え、バックアップの互換性、自動保存、編集モードの再生、発音管理、PWA更新、ルートとサブフォルダーでのオフライン配信を確認しました。

v6との比較でも、初期状態、音量操作、ミュート、キーボード操作、復元後の状態と表示・音声への反映が一致することを確認しています。今回整理した箇所以外のアプリ処理、HTML・CSS、音声復旧・パッド再生処理の一致も確認済みです。

音声処理・画面操作の自動テストには模擬環境を使っています。ブラウザでの実操作とiPhone実機の聴感・遅延は未確認です。

## 開発用テスト

Node.jsのある環境で、展開したフォルダーから次を実行できます。依存パッケージは不要です。

```text
npm test
```

`tests/` と `package.json` は開発用で、アプリの実行には不要です。`tests/fixtures/` の音声とバックアップは合成した確認用データです。

アプリはHTTP/HTTPSで配信して利用してください。実行ファイルを変更した場合は `sw.js` のキャッシュのバージョンも変更します。新しい実行ファイルは `SHELL` に追加します。今回はv7へ更新し、新しい2ファイルもオフライン起動の対象へ追加済みです。
