# サンプラー PWA — リファクタリング版

最新のiPhone表示修正版（v2）を整理した版です。画面・音源・保存データ・バックアップ形式を維持し、スタイル、サンプル生成、設定検証、IndexedDB、バックアップ、波形を別ファイルに分けました。黒い背景と不透明なステータスバーの設定も引き継いでいます。

音声の自動復旧機能は追加していません。既存の「音声を復旧」と、画面復帰時の再開処理を維持しています。

## 公開済みGitHub Pagesを更新する

1. このZIPを展開します。
2. 公開済みリポジトリで `index.html` が見える場所を開き、Add file → Upload files を押します。
3. ZIPの**中身全体**をアップロードし、mainブランチへ保存します。今回は以前の3ファイルだけでは動きません。新しい `styles.css` と **`js`フォルダー全体**も必須です。
4. Pagesの設定は `Deploy from a branch / main / (root)` のまま使えます。ビルドや依存パッケージのインストールは不要です。
5. 公開への反映後、iPhoneでメニュー →「アプリの更新を確認」→「保存して更新を適用」を選びます。

フォルダー名は変更せず、`index.html` と同じ場所に `js/`、`icons/`、`styles.css` が並ぶようにアップロードしてください。GitHubのWeb画面へドラッグするとフォルダー構造もまとめてアップロードできます。

## ファイル構成

```text
index.html                 画面とアプリ起動
styles.css                 画面のスタイル、iPhoneのセーフエリア
pwa.js                     オフライン準備状態と手動更新
sw.js                      アプリ全体のオフラインキャッシュ
manifest.webmanifest       ホーム画面のアプリ設定
icons/                     アプリ用アイコン
js/
  app.js                   画面操作・演奏・編集・自動保存の連携
  config.js                定数、上限、保存領域の識別子
  sample.js                サンプルの初期値、時間・範囲の計算
  presets.js               標準音源12個の生成
  session.js               保存設定の検証・正規化
  session-storage.js       IndexedDBの読み書き
  backup-codec.js          .sx12と旧JSONバックアップの読み書き
  audio-utils.js           音声出力経路とAudio Sessionの設定
  waveform.js              波形の集計と描画
tests/                     自動テストと合成した互換性確認データ
package.json               Node.jsでのテスト実行設定
.nojekyll                  GitHub Pagesの静的配信設定
README.md                  この手順書
```

`tests/`と`package.json`は開発用です。アップロードしても問題ありませんが、アプリの実行には不要です。`tests/fixtures/`の音声は互換性確認用に生成した短い波形で、ユーザーが取り込んだ音源ではありません。

## 保存データの互換性

保存領域の識別子 `sx12-local-sampler-v1` とバージョン1を維持しています。同じ公開URL・同じ起動方法で更新すれば、保存済みの音源と設定を引き継ぐ構成です。旧形式のJSONバックアップと現在の `.sx12` 形式を引き続き読み込めます。

PWAの更新前には音源と設定を保存します。保存が完了しない場合は更新を適用しません。新しいアプリファイルはオフラインキャッシュへ一式をそろえてから使います。演奏中に自動でページを再読み込みしません。

## iPhoneで使う

Safariで公開URLを開き、共有 →「ホーム画面に追加」。ホーム画面から起動し、オンラインでメニューに「オフライン準備済み」と出るまで待ちます。その後はオフラインで起動できます。元のHTMLや別URLから音源を移す場合は `.sx12` バックアップで復元してください。

## 開発者向け

Node.jsがある環境では、展開したフォルダーで次を実行できます。npm installは不要です。

```text
node --test tests/*.test.mjs
```

17件のテストで、旧版バックアップの読み込み、書き出すバイナリの一致、破損データの拒否、標準音源12個のPCMの一致、設定と波形、PWA更新時の保存確認、新しいCSS・モジュールのオフライン配信を検証しています。Service WorkerとPWA操作のテストには模擬環境を使っています。ブラウザ上の操作とiPhone実機での動作確認は未実施です。

今後アプリのファイルを更新するときは、`sw.js`の`CACHE_NAME`のバージョンも変更してください。実行に必要なファイルを増やした場合は`SHELL`にも追加します。ES modulesを使っているため、HTMLファイルの直接起動ではなくHTTP/HTTPSで配信してください。

保存領域を削除した場合や端末の空き容量が不足した場合に備え、大切な音源は `.sx12` でも残してください。
