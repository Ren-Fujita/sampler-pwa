# サンプラー PWA — GitHub Pages公開用

## GitHubで公開

1. GitHubで新しい公開（Public）リポジトリを作成します。例: `sampler-pwa`。
2. このZIPを展開し、**中のファイル・iconsフォルダーをリポジトリ直下にアップロード**します。ZIPそのものや、このZIPを展開した親フォルダーをアップロードする方法では動きません。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source: Deploy from a branch / Branch: main / Folder: /(root)** を選び、Saveします。
5. 配信完了後にPages設定に出るHTTPS URLを使います。通常は `https://ユーザー名.github.io/リポジトリ名/` です。

公開先の直下に `index.html`、`manifest.webmanifest`、`sw.js`、`pwa.js`、`icons/` が並んでいれば正しい構成です。ビルド、Node.js、GitHub Actionsの手動設定は不要です。

## iPhoneにアプリとして追加

1. 公開URLをiPhoneのSafariで開きます。
2. 共有メニュー →「ホーム画面に追加」。
3. 「Webアプリとして開く」が表示されたらオンにし、「追加」。
4. ホーム画面の「サンプラー」から起動します。
5. オンラインのままメニューに「オフライン準備済み」と出るまで待ちます。その後はオフラインでも起動・演奏できます。
6. 初回は「再生」モードを一度タップして音を有効にしてください。

HTMLファイルを「ファイル」アプリから直接開く方法ではPWAの準備はできません。公開後のHTTPS URLを使ってください。

## 元のサンプラーから音源を移す

元のサンプラーのメニューで「バックアップを保存」し、`.sx12`ファイルをiPhoneへ渡します。ホーム画面のアプリを開き、メニューの「バックアップを読み込む」で復元してください。新しい音源もホーム画面のアプリで取り込んでください。

## 追加した機能

- ホーム画面用アイコン、アプリ名、アドレスバーのない独立した画面での起動
- Service Workerによるアプリ本体のオフラインキャッシュ
- メニューでのオフライン準備状態表示、iPhoneへの追加手順
- 更新はメニューから手動適用。音源と設定を保存してから再起動し、演奏中の自動再読み込みを防止
- 対応端末では、ホーム画面からの起動時に保存領域の永続化をリクエスト
- 既存のタッチ操作、画面サイズへの対応、音源の自動保存とバックアップ

## ファイル

```text
index.html
manifest.webmanifest
pwa.js
sw.js
icons/
  apple-touch-icon.png
  icon-192.png
  icon-512.png
  icon-maskable-512.png
.nojekyll
README.md
```

`.nojekyll`がアップロード画面に出ない場合も、このアプリにはJekyll専用のファイルがないため、そのまま公開できます。

## 今後アプリを更新するとき

`sw.js`の`CACHE_NAME`末尾（例: `2026-10-15-v1`）を新しい値へ変更し、変更したファイルと一緒にGitHubへアップロードします。ユーザーはアプリのメニューから「アプリの更新を確認」→「保存して更新を適用」で反映できます。適用時に再生は止まります。保存に失敗した場合は適用を中止します。

同じGitHub Pagesドメインに複数のサンプラーを配置した場合、音源保存は同じドメインのIndexedDBを使うため共有されます。独立した音源保存が必要な場合は、別のドメインで公開するか、`index.html`内の`STORAGE_NAME`を別の値にしてください。

## 保存・動作確認について

GitHubではプログラムのソースが公開されます。取り込んだ音源・設定は端末内に保存し、サーバーには送信しません。`.sx12`バックアップをGitHubにアップロードする必要はありません。

Safariとホーム画面アプリの保存状態が異なる場合や、公開URLが変わる場合はバックアップで移行してください。端末の空き容量不足やサイトデータの削除で音源が消える場合があるため、大切な音源は`.sx12`でも保存してください。画面ロックやバックグラウンド中の再生継続はiOSの動作に依存します。

構文、manifest、アイコンの寸法、Service Workerのルート・サブフォルダーでのキャッシュ処理、オフライン応答、明示的な更新適用、ログイン画面へのリダイレクト拒否を自動検証しました。ブラウザ上の操作とiPhone実機での音声・インストール・機内モードでの再起動は未検証です。公開後にメニューの「オフライン準備済み」を確認し、機内モードで再起動・演奏を確認してください。

参考: [GitHub Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[Appleのホーム画面への追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)。
